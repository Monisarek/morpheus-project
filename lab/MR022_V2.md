# MR-022 V2 preflight

The V2 protocol inherits the official original AqSolDB V1 source, population, descriptors, model and evaluation unchanged. The only scientific change is the whole-scaffold selection rule in the V2 protocol. The V1 block remains historical evidence.

V2 uses the V1 eligibility function unchanged. It immediately projects its output to canonical identity and scaffold before selection. Target and cap are computed with integer arithmetic. Within each partition the original eligible row order is preserved. An independent algebraic check verifies each actual scaffold decision. The aggregate manifest binds the reconstructed cohort and ordered assignment without publishing structures or labels.

Use the original official CSV and the V1 Dataverse release metadata. The existing V1 Docker dependency volume is required. The runner checks the published metadata, original size, MD5 and SHA-256 and the pinned runtime. It mounts the inputs and dependencies read-only and has no model module, fit phase or checkpoint write mount.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/aqsol_v2_docker.ps1 -OriginalCsv $original -DataverseMetadata $metadata -Trial primary
```

Only after a passing primary run, repeat the exact command with `-Trial verify` to check reproducibility. This starts a fresh container with the same code, inputs, algorithm and seed. Compare the complete aggregate outputs. A failed gate stops V2. A fresh independent reproduction may use a separate clean worktree. Keep both local output files and commit only the aggregate manifest.

**Model fitting, negative controls and holdout metrics require a separate Lyra GO_RUN decision.**
