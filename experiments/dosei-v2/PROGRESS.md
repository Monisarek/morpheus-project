# Ход работы

## 2026-11-07

В корне только два входных Markdown-документа. Исходного кода, локальных данных и Git-репозитория при старте нет. Зафиксированы [спецификация](SPEC.md), [протокол](RESEARCH_PROTOCOL.md) и [бэклог](BACKLOG.md).

Среда выполнения Windows 10, Python 3.10.11, 4 видимых логических CPU, 15,9 ГиБ RAM, около 42 ГиБ свободно. Размеры ресурсов отличаются от исходного описания. Системные запросы CIM отклонены, поэтому паспортные данные CPU/GPU не подтверждены. План расчёта использует CPU и потоковое чтение.

Сверены релиз DOSE-I, опубликованные условия и документация полей. Архивы v2 загружены из Zenodo через разрешённый сетевой вызов. MD5 сырого архива, метаданных, статических данных, артефактов и pEEG совпадают с опубликованными значениями. Сырой архив содержит 171 ID записи, соответствующий 171 ID из метаданных.

Первая проверка на одной тренировочной записи подтвердила заголовок, сетку 4 мс, каналы ЭЭГ и исходные клинические метки. Публикуемые pEEG вычислены с использованием будущих отсчётов, поэтому в протокол прогноза вошли признаки из сырой ЭЭГ.

Сплит заморожен с seed 9000. В train 102 записи, в validation 34, в holdout 35. Проверка CLI `inspect` подтвердила 171 запись. Все 18 тестов прошли в изолированном окружении Python 3.10.11.

Этап `build` обработал 136 записей разработки. Из них 135 разобраны, одна запись исключена из-за нарушения сетки 4 мс. Извлечены 926 переходов LOC/ROC, 6 102 оценки MOAA/S и 15 048 окон, из которых 5 320 получили `FAIL` и 9 728 получили `WARN`. В validation исключены по QC 292/827 окон с переходом и 733/2 123 окон без перехода. Первичное сравнение ограничено оставшимися окнами с наблюдаемым горизонтом. [Сводка QC](runs/dosei-v2/qc_summary.json)

На validation сформированы описательные траектории вокруг 53 меток LOC и 39 меток ROC и список наиболее выраженных изменений альфа-мощности для последующей проверки. Сдвинутые события и стратификация по зарегистрированным болюсам входят в сводку. [Траектории](runs/dosei-v2/trajectory.json)

Baseline на validation показал AP 0,360 для ЭЭГ с контекстом и 0,327 для времени и болюсов. Парная разность +0,033 (95% ДИ от −0,013 до +0,086). Три контрольные проверки выполнены. Вариант H01 с изменениями мощности между окнами проверен и отклонён независимым агентом до открытия holdout. [Метрики](runs/dosei-v2/metrics.json) · [Решения](research/decisions.jsonl)

Повторный расчёт baseline на замороженных признаках дал побайтово совпадающий `metrics.json`. Повторное извлечение 117 окон из одной сырой тренировочной записи также совпало по всем полям. Повторно выполнены 18 тестов. После сверки доказательств запущена финальная оценка исходного кандидата. [Заморозка](runs/dosei-v2/candidate.json) · [Журнал открытия](runs/dosei-v2/holdout_release.json)

Однократная финальная оценка завершена. Holdout дал AP 0,360 для ЭЭГ с контекстом и 0,283 для времени и болюсов, парная разность +0,078 (95% ДИ +0,020…+0,135). Всего разобраны 169 из 171 записей с 1 112 метками переходов и 7 253 оценками MOAA/S. Исключены две записи с нарушением временной сетки. На holdout QC исключал 41,2% наблюдаемых окон с переходом и 33,3% без него. [Отчёт](reports/SCIENTIFIC_REPORT.md) · [Финальные метрики](runs/dosei-v2/holdout_metrics.json)
