# DOSE-I v2. Контекст для научного ревью

Цель — прогноз клинической отметки LOC/ROC в следующие 60 секунд по предыдущим 30 секундам ЭЭГ. Контроль использует время и историю болюсов. Сплит по записям 102/34/35, seed 9000. Независимость по людям не подтверждена. Авторские pEEG исключены из прогноза из-за использования будущих отсчётов.

На holdout AP 0,360 для ЭЭГ с контекстом против 0,283 для контекста. Парный прирост +0,078, 95% ДИ +0,020…+0,135. На validation интервал включал ноль. QC исключил 41,2% наблюдаемых положительных окон против 33,3% отрицательных. Это ограничивает вывод окнами с наблюдаемым горизонтом, прошедшими QC.

H01, разности мощности между окнами, отклонена до открытия holdout по заранее заданному порогу. Выполнены три контрольные проверки. Повтор baseline побайтово совпал. Две записи исключены из-за дубликатов временных отметок.
