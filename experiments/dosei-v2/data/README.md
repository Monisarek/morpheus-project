# Локальные данные

DOSE-I v2 размещается в `data/dose-i/`. Перед запуском сверьте [условия DUA](https://zenodo.org/records/22145442/files/Data_Use_Agreement.txt?download=1) и [контрольные суммы](../DATA_SOURCES.md). CLI читает `data.zip` напрямую. Архивы, индивидуальные события, признаки и артефакты запусков исключены из Git.
