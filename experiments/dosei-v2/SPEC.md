# MORPHEUS / О-СОЗНАНИЕ-9000

[Исходная спецификация](MORPHEUS_OCONSCIOUSNESS_9000_SPEC_v1.md) определяет научные вопросы и критерии приёмки. Первый рабочий этап E00–E07 проверяет прогноз клинически размеченного перехода поведенческой отзывчивости на DOSE-I v2. Правила оценки зафиксированы в [протоколе](RESEARCH_PROTOCOL.md).

Первый путь исполнения читает исходный CSV DOSE-I из ZIP, сохраняет исходную шкалу событий, измеряет качество и извлекает признаки из прошедшего окна. Разделение выполняется до анализа меток. Результаты должны содержать числители и знаменатели, причины исключений, контроль по времени и лекарству, оценку неопределённости и сведения для повторного запуска. Метки SOC — результаты наблюдения за ответом на команду. Единица клинического вывода ограничена опубликованным протоколом эндоскопии.

Порядок работ, доказательства и ограничения указаны в [бэклоге](BACKLOG.md).
